这件事大部分时候不完全由你定。多数人走的路是：没有剖宫产的医学原因，先试着顺产，大部分人生下来了，小部分人中途改成剖。

真正要自己拿主意的是三种情况：没有医学原因但想剖；医生说“两种都可以”；上一胎是剖的，这一胎想顺。

## 先看结论

- **没有剖宫产指征**：顺产。恢复快，并发症少，不影响以后再生。
- **有明确的指征**：剖。这时候剖宫产是更安全的那条路，不用纠结。
- **介于两者之间**：看下面的对比，再带着[最后一节的问题](#拿去问医生的问题)去问产检医生。

## 两种方式的对比

<Compare>

|  | 顺产 | 剖宫产 |
| --- | --- | --- |
| 过程 | 第一次生的人，从规律宫缩到生出来平均十来个小时，长的超过一天 | 手术约一小时，孩子在开头十分钟内取出 |
| 什么时候疼 | 疼在产程里，可以打无痛。生完之后疼得轻 | 手术时不疼。麻药退了以后伤口疼、宫缩疼，头两三天最重 |
| 住院 | 2–3 天 | 4–6 天 |
| 恢复 | 当天能下地，一两周行动自如 | 第二天下地，伤口的不适持续两到六周，六周内不能提重物 |
| 近期风险 | 会阴裂伤；试产的人里约一到两成中途改成剖宫产 | 出血更多；感染、血栓、麻醉并发症的风险高于顺产，不过绝对值都低 |
| 盆底 | 漏尿和脱垂的风险更高 | 低一些。怀孕本身已经造成了一部分损伤，所以不是零 |
| 下一胎 | 基本没影响，一般一胎比一胎快 | 子宫上留了瘢痕：下一胎前置胎盘、胎盘植入、子宫破裂的风险升高。至少隔 18 个月再怀 |
| 对孩子 | 经过产道挤压，出生后呼吸问题少 | 39 周前做的择期剖宫产，孩子呼吸问题多一些 |
| 费用（公立，报销前） | 约 4,000–10,000 元 | 约 8,000–18,000 元 |

</Compare>

## 哪些情况应该剖

**产前就能确定的**

- 前置胎盘，或前置血管
- 胎位不正：横位；足月仍是臀位，并且估计体重超过 3,500 克或脚先露
- 做过两次以上剖宫产，或做过切开了子宫全层的手术（比如某些肌瘤剔除）
- 双胎里靠下的那个不是头朝下；三胎及以上
- 孕妇有不能耐受顺产的严重疾病：某些心脏病、重度子痫前期等
- 估计是巨大儿：孕妇有糖尿病且估重 4,250 克以上
- 产道有畸形或被肿瘤挡住
- 生殖道有会传给孩子的严重感染，比如活动期的生殖器疱疹

**产程中才出现的**

- 胎儿窘迫：胎心监护显示孩子缺氧
- 产程停滞：宫口不再开，或者孩子下不来
- 脐带脱垂
- 胎盘早剥

后面这四种事先没法预知。这也是为什么选医院要看它能不能在夜里随时拉上手术台。

## 常见的想法，哪些成立

<Point verdict="myth" title="剖宫产不疼，也更安全" gist="疼只是换了时间。对没有指征的人，剖宫产的风险更高。">

**疼** 顺产疼在生之前，可以用无痛压下去。剖宫产疼在生之后：伤口加上宫缩，咳嗽、翻身、下床都疼，这时候还要开始喂奶、照顾孩子。

**安全** 剖宫产是开腹手术。出血、感染、血栓、麻醉意外、伤到膀胱和肠道，这些风险都比顺产高，虽然绝对值不大。更大的代价在以后：子宫有了瘢痕，下一次怀孕时胎盘长在瘢痕上的风险升高，那是产科最凶险的情况之一。

</Point>

<Point verdict="myth" title="高龄、近视、脐带绕颈、孩子偏大，就得剖" gist="这些都不是单独的剖宫产指征。">

- **年龄**：35 岁以上并发症多一些，但年龄本身不是理由。
- **近视**：高度近视的人如果眼底检查没有视网膜病变，可以顺产。拿不准就让眼科看一次眼底。
- **脐带绕颈**：四个孩子里就有一个绕颈，绝大多数不影响顺产。产程中有胎心监护盯着。
- **孩子偏大**：B 超估重有一成到一成五的误差。只有估到 4,000 克以上（有糖尿病的 4,250 克以上）才会建议剖。

</Point>

<Point verdict="myth" title="剖宫产能保住盆底，身材恢复也好" gist="能少一部分盆底损伤，但换来一道伤口。身材和怎么生的没有关系。">

顺产的人漏尿、脱垂的风险确实更高，大约是剖宫产的两倍。但怀孕九个月本身就在压盆底，所以剖宫产的人也有不少漏尿。肚子松、腹直肌分离、妊娠纹，两种方式一样。

为了保盆底去做一个没有指征的手术，多数医生不建议。更划算的做法是孕期练盆底肌、34 周后做会阴按摩。详见[分娩损伤与恢复](/body/birth-injuries/)。

</Point>

<Point verdict="info" title="万一顺到一半改成剖，是不是两样罪都受了" gist="试产的人里约一到两成会这样。就算最后剖了，前面的宫缩对孩子也有好处。">

**概率** 第一次生的人试产，约一到两成中途改剖宫产，主要原因是胎儿窘迫和产程停滞。

**并不白受** 经历过宫缩的孩子，肺里的液体被挤出去一部分，出生后呼吸问题比直接剖的少。妈妈的身体也已经为泌乳做了准备。

**能降低概率的事** 孕期体重和血糖控制好，孩子别太大；等自然发动，不做没必要的催产；产程中有人全程陪着（持续的陪伴支持能降低剖宫产率，这是有研究的）。打无痛不会增加改剖的概率。

</Point>

<Point verdict="info" title="没有指征，就是想剖" gist="可以提。医生会和你谈清楚风险，手术不会早于 39 周。">

怕疼、怕顺转剖、想选日子，这些想法很常见。国内外的指南都承认孕妇有这个选择权，条件是医生把利弊讲清楚。

提之前想两件事。一是如果主要是怕疼，先去了解[无痛分娩](/birth/epidural/)，很多人了解之后改了主意。二是打算生不止一个的话要慎重，每多剖一次，下一胎的胎盘风险就再高一截。

</Point>

<Point verdict="info" title="上一胎剖了，这一胎想顺产" gist="符合条件的人可以试，成功率六到八成，子宫破裂的风险不到 1%。">

**条件** 只剖过一次，是子宫下段的横切口；这一胎没有新的剖宫产指征；两次怀孕之间隔了 18 个月以上；孩子不太大。

**风险** 最担心的是试产时子宫沿旧瘢痕裂开，发生率不到 1%，但一旦发生要立刻手术。所以只能在随时能做急诊剖宫产的医院试。

**现实** 国内愿意做的医院不多，要早点问。不做的医院会直接给你排手术日期。

</Point>

<Point verdict="care" title="择期剖宫产不要早于 39 周" gist="37、38 周虽然算足月，孩子的肺还差一点。">

没有医学原因的话，手术排在 39 周以后。提前一两周，新生儿因为呼吸问题住进新生儿科的比例明显升高。为了某个日子把手术提到 37、38 周，不值得。

</Point>

## 拿去问医生的问题

孕 32–36 周的产检，医生会根据胎位、孩子大小和你的身体情况谈分娩方式。可以问：

1. 我有没有剖宫产的指征？是一定要剖，还是可以试试？
2. 按我的情况，试产中途改剖的可能性大概多大？
3. 这家医院夜里和节假日能不能打无痛？
4. 侧切率大概多少，什么情况下会切？
5. 产程中家人能不能陪？
6. 打算剖的：手术排在第几周？
7. 上一胎剖过的：这里做不做剖宫产后的顺产？
